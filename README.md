# О себе — Искусство и креатив

Лабораторная работа №2. Внешний CSS, переменные, позиционирование и состояния элементов.

**Автор:** Филимонова Ксения, группа 932401

## Что реализовано

- CSS-переменные в `:root` для цветов и шрифтов
- Три способа подключения стилей: внешний, внутренний `<style>`, inline
- Позиционирование: `static`, `relative`, `absolute`
- Состояния элементов: `:hover`, `:active`, `:focus`, `:visited`
- Подсветка активной секции при скролле (`.scroll-section.active`)
- Чёткая белая рамка 3px вокруг кнопки при `:focus`
- Иконка «Избранное» в углу карточки проекта (`position: absolute`)
- Моноширинный шрифт и внутренняя тень у `textarea`
- Полупрозрачный фон боковой панели через inline-стиль
- Контрастность текста не ниже 4.5:1

## Как открыть

Открыть файл `index.html` в любом браузере.
